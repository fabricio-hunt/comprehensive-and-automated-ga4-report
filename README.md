# comprehensive-and-automated-ga4-report

Automated monthly SEO reporting generator integrating Google Analytics 4 (GA4) and Google Search Console (GSC) APIs.

## Features
- Automated data collection from Google Analytics 4 (GA4) and Google Search Console (GSC)
- MoM (Month-over-Month) and YoY (Year-over-Year) automated KPI comparisons
- Smart keyword and page filtering (excluding brand misspellings, loan/financial terms, and internal pages)
- Interactive HTML reports and automated PDF export via Playwright
